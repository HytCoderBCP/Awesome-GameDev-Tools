# Awesome-GameDev-Tools
Here  is a list of tools for game development and what they are used for

## Tools
- Unreal (Game engine for graphics intensive games)
- Micro studio (Open source game engine for new developers to make their first game)
- 1BITDRAGON (Easy to use audio tool to make royalty free music for games)
- picoCAD 2 (Easy to use low poly 3d asset maker)
- Source 2 (High fidelity game engine used for game physics and VR)
- Aseprite (2d animation tool great for pixel art games)
- Godot (Free open source game engine good for both 2d and 3d games)
- Graillon (Voice changer allows you to make creative voices for your game)
- Daedalus (Procedural dungeons generator plugin for Unity)
- Unity (Game engine prominently used for mobile games)
